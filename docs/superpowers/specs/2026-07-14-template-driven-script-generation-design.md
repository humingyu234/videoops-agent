# 模板驱动的长口播台词生成规格

> **局部已被替代。** “一次只匹配一个模板、一次只生成一套台词”及相关生成、版本和计费规则，已由 `docs/superpowers/specs/2026-07-28-say-requirements-copy-generation-design.md` 的确定性知识路由、A/B/C 三套候选和不可变版本规则替代。

## 目标

数字人六步流程在收集行业、用途、问卷答案和补充信息后，使用 GLM-5.2 生成与需求匹配、可直接口播的完整台词。生成规则参考 `D:\Workspace\ai\projects\文案\` 下的 T01–T11 模板，不再受 120 字限制。

## 已确认设计

- 服务端根据行业、用途和问卷答案自动匹配一个模板，不要求用户理解或选择模板。
- 产品口播、短视频获客默认优先 T07；教学、揭秘、品牌故事、新品发布等场景分别匹配相应模板。
- 台词长度跟随模板：T01/T02 约 45 秒，常规模板约 90 秒，T03 约 120 秒。
- 只把匹配模板的结构规则和口播示例片段注入 GLM，不发送整个文案库。
- 模型必须基于用户提供的事实写作，不得从模板示例虚构品牌、价格、资质或效果承诺。
- 服务端负责生成脚本 ID、哈希、时长和连续分段，模型只负责台词正文，减少结构异常。
- 模型输出无法解析时自动重新请求一次；第二次仍异常才返回 `TEXT_MODEL_INVALID_RESPONSE`，前端显示“文本大模型返回内容异常，请重新生成”。
- 台词编辑框不显示字数计数，也不设置字符上限；所有后续脚本请求契约同步取消 120 字上限。

## 验收

- “电商零售 + 产品口播”能生成约 300 字的 T07 风格台词。
- 返回台词可超过 120 字，并能进入确认台词页面编辑。
- 非法第一次响应会触发一次真实重试，合法第二次响应成功返回。
- 两次响应都非法时流程阻断且保留用户已填写需求。
