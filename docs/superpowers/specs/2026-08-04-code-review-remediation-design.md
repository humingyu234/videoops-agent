# 当前工作区代码审查修复设计

## 1. 目标与范围

本轮只处理当前工作区中已经通过代码、规格和测试确认的审查问题，不新增形象生成后端、异步任务、额度扣减或新的公共接口。

涉及范围：

- 登录页测试、认证文件冻结边界和页签键盘操作。
- 形象列表进入形象空间时的形象身份与短期访问地址生命周期。
- 形象空间本地图片类型限制、异步回调隔离和演示行为的真实表达。
- 本地 Maven 缓存与诊断临时文件的 Git 忽略规则。

## 2. 已确认的技术决策

### 2.1 登录页

- 页面继续只展示“账号密码”和“扫码登录”两个页签；这符合最新登录页规格，不恢复短信、邮件、第三方和小程序入口。
- 登录固定使用非持久会话；测试改为验证 `persistent=false`。
- 更新 `antd` 测试桩，使其支持当前 `Form`、`Form.Item` 和表单提交行为，同时保留登录失败、安全回跳、重复提交、`/me` 校验和 403 会话处理覆盖。
- 回退 `src/services/ai-video/auth/api.ts` 的本轮差异，恢复该冻结文件原有运行时适配器组装；额度模块继续独立使用共享运行时适配器。
- 页签补齐左右方向键、Home、End、焦点迁移和 roving `tabIndex`，不改变现有视觉样式。

### 2.2 形象列表与形象空间

- 从形象卡片进入形象空间时传递稳定的 `portraitId` 和名称，不把 120 秒 `previewUrl` 当作长期身份。
- 形象空间通过现有 `portraitApi.accessUrl(portraitId)` 获取短期地址；加载失败或地址失效时允许重新获取，不新增后端接口。
- 本地重新选择图片只接受 JPEG、JPG、PNG、WebP 和 GIF；前端按扩展名与浏览器 MIME 做即时拒绝，并使用 `Locale.ROOT` 或等价方式忽略元数据大小写。文件头由后端按原始二进制精确匹配，不做大小写处理。由于当前文件不会上传到服务端，本轮不伪造“已完成服务端安全校验”的结论；未来接入上传时必须复用现有后端 `PortraitImageValidator`，继续拒绝 BMP、SVG、HEIC/HEIF 和 AVIF，且只做类型安全校验，不做人脸、清晰度、构图或内容审核。
- 换图、返回列表或来源形象改变时，使旧定时回调失效，避免旧结果写入新形象会话。

### 2.3 生成与保存行为

- 当前仓库没有形象修改生成、任务追踪和保存结果的公共契约，本轮不临时创造接口或任务状态。
- 页面可以保留原型视觉和输入交互，但必须明确标识为演示或建设中。
- 不再把第三方随机图片描述为真实生成结果，也不再显示“已保存到形象库”的业务成功提示。
- 待后续生成模块规格明确任务、额度、文件归属和保存接口后，再接入真实生成与保存能力。

### 2.4 仓库卫生

- 根 `.gitignore` 增加 `/.m2/` 与 `/.codex/tmp/`。
- 不删除用户当前已有的本地缓存或诊断文件，只避免其进入版本控制范围。

## 3. 数据流

1. 用户从形象卡片点击“进入形象空间”。
2. 页面传递 `portraitId + name`。
3. 形象空间调用现有访问地址接口获取当前短期 URL，并显示加载、失败和重试状态。
4. 用户重新选择本地图片时，先执行 JPEG/JPG/PNG/WebP/GIF 类型校验，再生成仅用于当前页面的本地预览。
5. 来源改变时递增会话版本；所有延迟回调执行前校验版本，不匹配则丢弃。
6. 未接入真实生成服务前，页面不产生可保存的业务结果。

## 4. 错误与边界处理

- 短期地址请求失败：保留形象名称，显示加载失败与重试入口，不要求用户重新上传。
- 不支持的图片类型：保持原形象与当前会话不变，显示仅支持 JPEG/JPG/PNG/WebP/GIF。
- 用户快速换图：旧加载结果和旧定时回复不得覆盖新来源。
- 认证失败：继续由现有统一请求层处理，不在形象空间重复实现登录跳转。

## 5. 测试与验收

- 登录页：两个入口、非持久会话、当前错误矩阵、安全回跳和完整键盘页签模型通过。
- 认证 API：`auth/api.ts` 相对当前分支基线无差异，既有 API 合同测试通过。
- 形象空间前端：从 `portraitId` 获取访问地址；地址失败可重试；本地选择仅校验 JPEG/JPG/PNG/WebP/GIF 的扩展名和浏览器 MIME，匹配时大小写不敏感，不承担文件头校验；换图后旧回调不再写入，页面不提示虚假生成或保存成功。
- 后端 `PortraitImageValidator`：校验二进制文件头、类型错配、空 MIME、截断 GIF/WebP，并拒绝 BMP、SVG、HEIC/HEIF、AVIF 和其他类型；前端即时校验不能替代该服务端结论。
- 工程验证：相关 Vitest、TypeScript 类型检查、后端既有定向测试和 `git diff --check` 通过。

## 6. 风险与明确不做

登录认证属于红色风险边界，因此认证 API 只允许回退越界差异，不做等价重构。形象空间本轮是前端行为纠偏，不新增生成后端、数据库字段、任务、额度或文件持久化，也不进行人脸、清晰度、构图或内容审核。
