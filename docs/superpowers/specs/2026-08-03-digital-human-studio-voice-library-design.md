# 数字人工作台声音菜单一比一复刻设计规格

## 1. 结论与权威来源

本规格冻结 `ai-video-ui/ai-video-webapp` 中数字人工作台内部“声音”菜单的前端复刻范围。
唯一视觉与交互基准是 `D:\AI\digital-human-studio.html` 中可到达的“声音”菜单实现，目标是在
现有 React + TypeScript + Ant Design 工作台外壳内实现用户可观察的一比一等价，不重新设计，
不补充参考页没有的入口，不把本次工作扩展为生产级声音克隆系统。

同时遵守以下项目规则：

- `RULES.md`
- `docs/FRONTEND_GUIDE.md`
- `docs/FRONTEND_CODING_STANDARDS.md`
- `docs/API_CONTRACT.md`
- `docs/AI_AGENT_GOVERNANCE.md`
- `docs/AI_CODING_RULES.md`
- `ai-video.md` 与 `ai-video-pages.md` 对声音资产的产品背景

用户已经确认：采用独立声音组件方案，并要求完全按参考页面一比一实现。

## 2. 目标、范围与不做范围

### 2.1 单一目标

将当前工作台“声音”菜单从“点击卡片打开详情抽屉的静态波形列表”，替换为参考页的声音资产
列表：搜索、双筛选、本地分页、行内展开播放器、时间轴拖动/点击跳转、字符级朗读高亮、
示范文案原位编辑，以及现有的“上传原声”弹窗。

### 2.2 本次必须实现

- 保留当前工作台侧栏、顶栏、认证门禁和路由方式；进入内部 `voices` 路由时菜单保持高亮。
- 工具栏顺序、文案和控件：声音名称搜索、全部类型/克隆/原声/公共、全部状态/已校验/校验中、
  上传原声、匹配总数。
- “声音列表”标题、数量徽标、每页 6 条、本地分页与区间信息。
- 7 条参考声音数据的名称、类型、归属、元信息、时长、秒数、状态、示范文案与分句。
- 卡片收起态、展开态、播放态及参考页对应的颜色、边框、圆角、间距、字号、标签和箭头旋转。
- 同一时间只能有一条声音处于播放状态；开始新声音时停止并复位上一条。
- 播放按钮从开头播放；播放中再次点击停止；播放会自动展开当前卡片。
- 时间轴支持单击跳转和按住拖动跳转，并同步当前时间、填充宽度、播放头位置和字符高亮。
- 点击任意汉字或中文标点从该字符的时间点开始播放。
- “编辑”进入原位编辑；“取消”恢复原文并保持卡片展开；“保存”更新本地文案和分句，
  空文案提示“文案不能为空”，成功提示“文案已保存”。
- 搜索和筛选没有结果时展示“没有匹配的声音 / 试试调整筛选或上传原声音”。
- “上传原声”继续使用现有 Ant Design Modal，并保持参考页的标题、上传区、格式/时长说明、
  声音名称、备注、警告、取消和“上传并保存”反馈。

### 2.3 明确不做

- 不新增真实音频文件选择、读取、解码、上传、下载或播放 URL。
- 不新增声音质量检测、真实声音克隆、任务、轮询、通知、额度、数据库或后端 API。
- 不新增或修改 `docs/API_CONTRACT.md`、`docs/DOMAIN_MODEL.md`、`docs/ASYNC_TASKS.md` 中的公共契约。
- 不重构形象、文案、作品或创作步骤页面。
- 不改变用户现有的 `StudioSider.tsx` 品牌文案修改。
- 不从声音卡片打开详情抽屉。参考页的 `openVoiceDrawer` 只有未被调用的函数，没有可到达入口；
  用户可观察的一比一行为以“点击整行展开/收起”为准。
- 不引入参考页之外的排序、批量操作、下载、重命名、删除、选择当前或额外详情入口。

## 3. 风险等级与任务边界

### 3.1 风险等级

本任务定为黄色中风险。

降级依据：本次只改变用户可见的前端本地模拟行为；不接触真实文件、外部 AI 服务、账号归属、
权限字典、额度、任务状态、公共接口、数据库或不可逆数据。认证加载、匿名跳转和 403 仍由现有
`StudioAuthGate` 处理，不在本次修改范围内。

如果实施中发现必须接入真实文件或线上 API，立即停止并重新按红色高风险任务梳理规格，不得把
该扩展隐含进本任务。

### 3.2 最小任务卡

- 目标：完成参考页声音菜单的视觉与交互等价复刻。
- 允许影响：数字人工作台声音菜单组件、对应本地模型/纯函数/Hook、局部样式和测试。
- 不允许影响：认证、其他菜单、创作步骤、公共服务、后端、公共契约和用户未提交修改。
- 实施方式：一名实施者；完成后进行一轮独立审查，修复后只定向复核差异。
- 强制验证：声音组件测试、现有数字人工作台测试、TypeScript、Biome、生产构建和浏览器人工验收。
- 输出：完成项、风险、验证证据、阻塞项。

## 4. 视觉和布局设计

### 4.1 页面结构

沿用现有工作台外壳。声音内容区固定为：

1. `page-toolbar`：搜索框、类型分段控件、状态分段控件、上传按钮、右侧总数。
2. `library-list-title`：标题“声音列表”和当前匹配总数徽标。
3. `voice-list`：纵向声音卡片列表。
4. `pagination`：仅总页数大于 1 时展示。

工具栏、搜索框、分段控件和分页继续复用当前工作台已经与参考页一致的通用样式；声音卡片使用
参考页专用 `vcard`、`vrow`、`vplayer`、`vtimeline`、`vptext` 等样式边界，避免改变其他资产列表。

### 4.2 卡片视觉状态

- 默认：白底、`1px` 柔和边框、`14px` 圆角、行内 `11px 15px` 内边距。
- 悬停：整行使用暖白表面色。
- 展开：边框使用主色，箭头旋转 90 度，播放器区域展开并出现顶部分隔线。
- 播放：主色边框和 `3px` 主色柔光环，播放按钮切换暂停图标。
- 不使用静态波形条替代行内时间轴；当前 React 页面中的列表波形会被参考页时间轴取代。
- 字符状态：未播放为弱色，已播放为次级正文色，当前字符为主色、半粗体和主色浅背景；标点保持
  更弱颜色但仍可点击跳转。

### 4.3 响应式和可访问性

- 保留工作台现有 `920px` 响应式断点和底部导航，不为声音菜单创建第二套页面壳层。
- 小视口下工具栏按现有规则纵向排列；卡片内容仍保持可滚动、可展开和可操作。
- 播放、编辑、保存、取消、分页和上传都使用原生 `button`，提供可访问名称与可见焦点。
- 卡片行使用按钮之外的可聚焦语义容器，支持 Enter/Space 展开，避免交互按钮嵌套。
- 颜色不是唯一状态表达；标签文字、播放/暂停图标和展开箭头共同表达状态。

## 5. 组件与文件边界

### 5.1 `LibraryView.tsx`

`LibraryView` 继续负责形象、文案和作品三个资产页。`route === 'voices'` 时只委托给独立
`VoiceLibraryView`，不再在 700 行通用组件内维护播放器、拖动和编辑状态。

### 5.2 `voices/VoiceLibraryView.tsx`

声音菜单容器，职责只有：

- 管理搜索词、类型筛选、状态筛选、页码、展开声音和本地可编辑声音集合。
- 派生过滤结果、总页数、当前页数据和空状态。
- 渲染工具栏、标题、列表、分页并调用 `onAddVoice`、`onToast`。
- 把单卡片播放/跳转/编辑事件连接到播放 Hook 和本地模型。

筛选结果、分页切片和标签文字均在渲染阶段派生，不创建镜像 state。

### 5.3 `voices/VoiceCard.tsx`

纯展示/交互组件，输入一条声音、展开/播放/编辑状态、时间轴数据和业务回调。它不直接查询 DOM、
不持有全局监听器、不修改数据源，也不决定另一个卡片是否停止。

### 5.4 `voices/useVoicePlayback.ts`

播放器 Hook 使用 `requestAnimationFrame` 模拟参考页进度，不播放真实媒体。它维护唯一活动声音、
当前百分比和播放状态，并提供：

- `play(voice, startPercent)`
- `stop()`
- `toggle(voice)`

切换声音、筛选导致活动声音离开列表、路由离开和组件卸载时都取消动画帧并清理状态，防止卸载后更新。

### 5.5 `voices/voiceTimeline.ts`

纯函数承载参考算法：

- 按字符拆分句子并按字符数分配持续时间。
- 合并全部分句的字符时间轴。
- 将秒数格式化为 `m:ss`。
- 按中文逗号、句号、问号、叹号、顿号、分号、冒号和换行重新分句。
- 根据秒数生成 5 秒或 10 秒刻度与主要刻度标签。

这些函数不访问浏览器 API，使用确定性单元测试覆盖。

### 5.6 `model.ts` 和 `style.css`

- 为声音数据增加显式 `VoiceItem` 类型及 `secs`、`script`、`sents` 字段，并把 7 条模拟数据更新为
  参考页的精确值。组件用可写副本处理本地编辑，不直接修改导出的常量。
- 在现有 `style.css` 中加入参考页声音菜单专用样式；不改全局主题，不覆盖 Ant Design 内部类名。
- 保留详情抽屉给其他资产页面使用；声音路由不再调用现有 `openVoice`。

## 6. 状态与数据流

### 6.1 筛选和分页

- 初始值：搜索空、类型 `all`、状态 `all`、页码 `1`。
- 搜索范围：名称和 `meta`，中文按字符串包含匹配，名称同时兼容大小写不敏感。
- 搜索输入按参考页延迟 250ms 生效；新搜索或筛选把页码重置为 1。
- 页大小固定为 6；过滤后页码超过总页数时收敛到最后一页。
- 标题徽标和“共 N 条”都显示过滤后的总数，不显示原始 7 条。

### 6.2 展开和播放

- 点击行只切换该卡片展开状态，不打开详情抽屉。
- 可同时展开多条卡片；同一时间只能播放一条。
- 点击播放按钮不会额外折叠行；开始播放时强制展开当前卡片。
- 手动停止时按参考页保留当前时间轴位置和字符高亮，只把按钮恢复为播放状态；再次点击播放按钮
  仍从开头开始。自然播完时才复位时间、填充、播放头和字符高亮，并保持展开状态。
- 开始播放另一条时停止上一条并恢复上一条播放按钮；上一条的时间轴位置和字符高亮按参考页保留，
  直到它再次播放、筛选/分页重绘或自然播完。
- 筛选、分页或路由切换使活动条目不可见时停止播放。

### 6.3 跳转和拖动

- 时间轴单击位置换算为 `[0, 1]` 百分比并从该位置播放。
- 指针按下后进入拖动；窗口级移动持续换算位置；指针抬起或取消时结束拖动。
- 点击字符用该字符 `start / voice.secs` 作为播放起点。
- 所有百分比都裁剪到 `[0, 1]`，时长为 0 时不启动播放。

### 6.4 原位编辑

- 进入编辑先停止当前播放，并将当前文案复制到受控草稿。
- 保存时把连续空白归一为单个空格并去除首尾空白；空值不退出编辑。
- 保存成功后更新对应声音的 `script` 和 `sents`，退出编辑并保持展开。
- 取消丢弃草稿、恢复字符时间轴并保持展开。
- 本地编辑不会改变其他路由中的声音常量，也不会写 `localStorage`。

## 7. 页面状态、反馈和异常

- 认证加载、匿名跳转、403 和认证临时失败继续由 `StudioAuthGate` 负责并复用现有测试。
- 声音数据来自同步本地常量，因此本次不存在数据请求加载、网络失败或服务端权限状态；不得伪造
  一套 API 状态。
- 搜索/筛选无结果使用参考页空状态；原始数据为空时也复用相同空状态。
- 上传弹窗只模拟参考页反馈，不实际读取文件；点击上传区提示“请选择音频”，确认后提示
  “原声音已上传，正在校验”。
- 编辑空文案显示错误语义消息；保存成功和上传确认使用成功语义消息。
- 所有定时器、动画帧和窗口监听器在卸载时释放。

## 8. 前后端、契约与协作边界

### 8.1 前端

本次全部实现位于 `ai-video-ui/ai-video-webapp/src/pages/digital-human-studio`。不新增模块 Service、
RuoYi adapter 或线上 DTO；`VoiceItem` 是页面模拟数据类型，不得被描述为线上接口契约。

### 8.2 后端

本次没有后端任务，不创建 Controller、BO、VO、Entity、DTO、Mapper 或 Service，不涉及 RuoYi
分层、权限标识、`ownerId`、额度、任务、文件授权、字典或审计。也不引入 DDD、Clean
Architecture 或 Hexagonal Architecture 平行业务层。

### 8.3 公共文档

`docs/API_CONTRACT.md`、`docs/DOMAIN_MODEL.md`、`docs/ASYNC_TASKS.md` 和 `docs/ARCHITECTURE.md`
均不需要修改。若后续要求接入真实声音克隆能力，必须另起规格并先更新相应公共契约。

### 8.4 协作

- 本任务只有一个前端实现单元，不做并行写入。
- 模拟数据、纯函数、组件与测试可在本地完成，不等待后端。
- 若出现真实上传、线上声音 ID、声音任务状态或额度字段，视为公共契约扩展，必须停止实施并 review。
- 独立审查覆盖：参考页视觉/交互逐项对照、React 生命周期与无障碍、现有认证和其他资产页回归。

- 标点被识别，分句和 `m:ss` 格式正确。
- 5/10 秒刻度边界与参考页一致。

- 初始页显示 6 条和正确总数；第二页显示第 7 条。

- 行点击展开/收起；播放按钮不误触发行切换；新播放停止上一条。
- 进度推进更新当前时间、时间轴和字符状态；结束后复位。
- 时间轴单击、拖动和字符点击从正确位置开始。
- 编辑、取消、空值保存和有效保存路径正确。
- 点击“上传原声”调用现有弹窗回调。
- 卸载后没有遗留动画帧或窗口监听器。

### 9.3 回归和工程验证

- 现有 `index.test.tsx` 认证门禁测试全部通过。
- 形象、文案、作品路由的 DOM 与交互不因声音组件拆分改变。
- 运行受影响测试、完整 `npm test`、`npm run tsc`、`npm run biome:lint` 和 `npm run build`。
- 在工作台桌面视口人工对照参考源码的颜色、尺寸、间距、7 条数据、展开态、播放态、编辑态、
  空态和分页；再在窄视口检查控件可达性。

### 9.4 反向验收

- 不出现“点击声音卡片打开详情抽屉”的旧行为。
