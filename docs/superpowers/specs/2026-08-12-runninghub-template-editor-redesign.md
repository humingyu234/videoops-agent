# RunningHub 模板全页编辑器设计

## 状态与任务卡

- 日期：2026-08-12
- 模块：运营端工作流模板新增、修改、查看
- 状态：用户已确认
- 风险：黄色。仅调整运营端页面结构与交互，不修改 API、数据库、权限、执行模式或用户端 wire；仍需一次独立前端审查。
- 目标：把当前 840px 长抽屉改为参考 RunningHub 发布页信息层级的全页编辑器，让运营人员清楚完成模板资料、RunningHub 资源绑定、用户参数配置及输出运行设置。
- 非目标：不增加版本管理、发布范围、Standard/Plus、多执行配置、故障切换、自动选择、连接测试或真实生成；不修改 RunningHub 账号管理页及用户端页面。

## 参考页取舍

借用 RunningHub 发布页以下信息架构：

1. 顶部明确区分 AI App 与 ComfyUI 工作流。
2. 使用编号分区组织基本资料、输入参数与运行设置。
3. 配置区与用户输入预览并列。
4. 页面底部提供稳定、明确的保存操作。

不复制参考页的版本切换、多语言封面、发布范围、运行套餐和“发布为新作品”，因为这些不属于已冻结的单执行配置契约。

## 页面结构

列表页保持 ProTable、筛选、分页、启停和删除不变。点击新增、修改或查看后，在当前管理路由内切换为独立全页编辑器；返回后恢复列表，不新增后端菜单或平行静态路由。

全页编辑器从上到下为：

1. 页面标题栏：返回、场景标题、草稿/只读提示、取消和保存。
2. 执行类型卡片：`AI App（推荐）` 默认；`ComfyUI 工作流` 为辅助模式。切换时清空另一模式的资源 ID 与已读取参数，保留既有安全行为。
3. 双栏主体：左侧编辑内容，右侧固定“用户输入预览”。窄屏改为单栏，预览移到内容区末尾。
4. 基本信息：频道、名称、分类、封面资产、摘要、详情；标签、排序、预计耗时和推荐收进同区的运营设置。
5. RunningHub 资源：账号、当前模式对应的 Web App ID 或 Workflow ID，以及“读取 RunningHub 参数”。
6. 用户输入参数：使用紧凑列表显示用户名称、控件、必填与来源节点摘要；新增、编辑打开参数编辑面板，节点 ID、字段名、远端类型和选项放在高级映射区。
7. 访问安全：保留访问密码管理；输出类型、结果数量、唯一主结果和最大结果大小均不作为运营配置项。

## 状态与行为

- 新增、修改和只读查看复用同一编辑器；只读状态隐藏保存和参数变更操作。
- 打开编辑器前仍并行加载模板详情、执行配置、账号和分类；失败时停留列表，由请求层提示错误。
- 参数候选读取仍使用现有接口；空结果、失败和加载状态保持明确提示。
- 参数预览只展示用户可见的标签、说明、控件、必填、占位符和选项，不显示 RunningHub、节点 ID 或字段名。
- 保存仍先保存模板基础资料，再保存唯一执行配置。配置保存失败时保留当前页面和表单值，显示“草稿已保存，配置保存失败”，再次保存只重试配置。
- access password 仍遵守写入后不回显、留空保持、显式二次确认移除。
- 保留 `row_revision`、未知 JSON 属性往返、候选参数去重和字段级校验；不改变 `templateFormModel.ts` 的 wire 语义。
- 关闭或返回编辑器时清理表单秘密值和候选参数状态。

## 验收

- 新增、修改不再显示 840px 抽屉，而是完整页面编辑体验。
- AI App 默认且视觉优先；切换 Workflow 后只显示 Workflow ID。
- 参数不再以多张完整技术卡片平铺；可在紧凑列表编辑，并在右侧看到用户输入预览。
- 新增、修改、只读、加载失败、读取参数空/失败、保存中、保存成功、基础保存成功但配置失败及重试均可验证。
- 现有 API payload、权限、分类字典、账号加载、密码语义和启停流程不变。
- 定向 Vitest、TypeScript/lint、生产构建及 1440×900 浏览器验收通过。

## 2026-08-12 精简修订

- 删除运营端页面的“输出与运行设置”和“用户输入预览”；它们不是 RunningHub App 或 Workflow 的发布参数，不能再作为运营输入。
- `outputPolicy` 不再往返历史限制值，新建和编辑均固定提交 `{}`；数据库迁移删除历史类型、数量、唯一主结果和单文件大小策略键。超时和启用状态继续作为既有执行链路的内部兼容值，不新增接口字段。
- RunningHub 返回的所有有效结果均被接收，允许任意数量和混合类型；默认预览仅按返回顺序选取，不作为运营配置或任务成功条件。URL、非空和单文件固定安全上限等平台安全校验继续生效。
- 模板基础资料改为封面上传和富文本详情；移除标签编号、封面素材编号文本框和摘要输入，遗留数据不被本次编辑清空。
- 访问密码独立为“访问安全”，保持不回显、留空保持、二次确认移除的语义。
- Workflow 参数读取保留现有接口，但失败信息必须安全地区分 HTTP 状态、RunningHub `code/msg`、响应过大和无效工作流 JSON；不得输出 API Key 或原始响应。
