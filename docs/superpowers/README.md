# Superpowers 资料边界

本目录同时保存活动模板和历史规格/计划，二者权威性不同：

- `templates/`：生成新规格或实现计划时使用的活动项目模板。
- `specs/`：按当时需求、源码和讨论形成的点时间设计来源，默认只作历史参考，不代表当前能力或进度。
- `plans/`：按当时源码形成的点时间施工资料，默认只作历史参考。只有 `docs/EXECUTION.md` 当前明确点名的一份计划，才是本阶段的辅助 runbook。

即使计划被点名，实时 HEAD、工作区、步骤状态、证据、阻塞和现场动作仍只以 `docs/EXECUTION.md` 为准；runbook 只提供冻结边界、验收和执行方法。阶段结束或 `EXECUTION.md` 取消点名后，该计划自动恢复为历史资料。

不要为整理目录批量移动或改写历史规格/计划。旧链接、提交和讨论引用是来源证据；需要采用其中内容时，应先与 `docs/PROJECT.md`、`docs/DECISIONS.md`、`docs/ARCHITECTURE.md`、公共契约和当前源码核对，再把仍有效的事实前向同步到当前权威文档。
