# 运行证据目录

本目录只保存经过脱敏、能对应具体源码状态和验收项的证据索引或小型文本摘要。大型视频、原始素材和含隐私日志放在授权存储中，本仓库只记录安全引用与哈希。

建议目录为 `T1/`～`T7/`，证据编号为 `Tn-Exx`。每条记录至少包含：

- 支持的任务卡验收项；
- `REAL / DEMO / MOCK` 环境标签；
- 完整提交哈希，或 HEAD、dirty paths 与 diff 指纹；
- 精确命令、测试名、任务 ID（可脱敏）或产物引用；
- 时间、结果、失败和 `NOT_RUN` 项；
- 剩余风险。

禁止把 AI 总结、“看起来正常”、只打开页面、Mock 或过期截图当作真实边界完成证据。禁止提交 Token、密码、签名 URL、私有地址、用户隐私和未授权素材。
