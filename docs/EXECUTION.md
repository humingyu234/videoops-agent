- 当前命令环境上次预查找不到 Java 21；后端构建和启动前必须重验并解决。
- IndexTTS2 `39000` 与 ComfyUI `8189` 上次预查未监听，真实声音和底片无法据此宣称可生成。
- `8080` 被来源不明进程占用，不得擅自终止；T1 使用 `18080`。
- OSS、DeepSeek、目标数据库迁移、真实 `ready` 人物和 `origin` 声音尚未核验。
- Studio 步骤 0～4 的关键上下文主要在 React 内存，创建 `projectId` 前刷新会丢失任务上下文；T1 运行时不刷新，并记录为后续恢复边界。
- 当前数字人链使用 `av_dh_generation_job`，时间轴渲染使用 `av_ai_task`；证据必须分别记录，不能描述成已经统一。
- 当前仓库不能证明实际 ComfyUI checkpoint；未取得实际工作流前不能宣称具体 Wan 或 LTX 版本。
- 这些缺口目前不构成 `BLOCKED`，因为仍可安全完成开工和环境清点。

## 开工与收工协议

- 开工：读取本文件及其点名的当前辅助 runbook；确认绝对路径、分支、HEAD 和工作区。只有调整路线、范围或依赖时才读 `PLAN.md`。发现未记录改动时先查来源，不得覆盖。
- 进行中：只在步骤通过、状态变化、出现阻塞或准备交接时更新本文件；运行日志和大型产物留在授权存储，只在此记录脱敏摘要、安全引用与哈希。
- 收工：检查 diff，运行 runbook 规定的验证，记录失败和未运行项。AI 总结、静态阅读、Mock 或“看起来正常”不能单独支撑 `DONE`。
