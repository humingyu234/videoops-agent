# T5 三层质量评价

| 元数据 | 内容 |
| --- | --- |
| 卡片状态 | `DRAFT`，T4 通过后冻结并用 T1 样本校准 |
| 路线状态 | `NOT_STARTED` |
| 风险等级及原因 | `RED`：自动拒绝/返工决策、媒体文件、模型误判和业务事实 |
| 前置阶段 | T4 `DONE`，T1 有可复用真实样本 |
| 权威来源 | 参赛设计、`DECISIONS.md`、T1 证据与固定评价夹具 |
| 允许影响范围 | 评价 Service、媒体探测、确定性规则、模型适配、评价记录和测试夹具 |
| 实施/审查安排 | 确定性检查和感知模型分离；独立审查误报、漏报和证据可解释性 |
| 固定交付格式 | 完成项、风险、验证证据、阻塞项 |

## 1. 目标

建立媒体、内容版式、感知主观三层评价，并把结果映射到具体产物、时间段、失败维度和可修复阶段。

## 2. 用户可见行为

结果页不仅说“生成成功”，还说明能否播放、事实/字幕是否符合、主观项置信度和证据；用户能看懂为什么通过、拒绝或请示。

## 3. 修改边界

硬媒体与内容规则可以自动阻止交付；感知评价必须有证据和版本。没有真实样本校准前，主观项只建议或要求人工批准。

## 4. 非目标

不训练新模型，不建通用规则平台，不用一个黑盒总分，不让生成模型无证据评价自己，也不宣称能完全复制用户审美。

## 5. 验收场景

- 损坏/零时长/无音轨/比例错误 MP4 被确定性门禁拒绝。
- 必用事实缺失、禁用词出现、字幕漏字/越安全区被内容版式门禁拒绝并定位。
- 合格固定样例通过相应硬门禁，避免全拒绝的假安全。
- 低置信风格偏差只给建议或进入人工批准，单个模型分数不能自动重跑。
- 每项结果保存 criterion code、评价器/策略版本、产物版本和证据引用。

## 6. 验证与证据

使用最小正负夹具证明误报与漏报边界；用 T1 真实 MP4 运行当前评价器。阈值必须来自记录的样本与测量，不得直接写拍脑袋数字。
