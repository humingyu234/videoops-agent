## 1. 目标

从已缓存公司主线建立不携带原 Git 历史的独立、可追溯、脱敏参赛基线。

## 2. 用户可见行为

项目可在 `D:\project\videoops-agent` 独立打开，保留原产品代码和清晰来源说明，不暴露原仓库历史。

## 3. 修改边界

只处理快照、密钥/私有地址占位、`.gitignore`、安全脚本和文档，不改变产品运行行为。

## 4. 非目标

不证明当前代码可运行，不证明真实 Provider 可用，不替代旧凭据轮换，也不等于已满足 GitHub 发布要求。

## 5. 验收场景

- Given 已缓存来源提交，When 使用无历史快照导入，Then `docs/BASELINE.md` 能追溯来源且新仓库有独立提交。
- Given 配置出现敏感键，When 导入公开基线，Then 真实值不进入新 Git 提交，使用环境变量或空示例。
- Given 原项目历史曾出现凭据，Then 文档明确要求在提供方轮换，不能用“已删除当前值”代替吊销。
